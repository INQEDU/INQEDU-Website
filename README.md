# Ink & Quill (INQEDU) website

The website for Ink & Quill, an IB tuition centre.

## How it is put together

- `build.py` holds the text of every page, the shared header and footer, and the list of guides.
- `subjects.py` holds each subject's page: description, what we cover, assessment table and **class slots**. Instructions for adding slots are at the top of that file.
- `site/` is the finished website that visitors see. It is generated by `build.py`, apart from `site/css`, `site/js` and `site/assets`, which are edited directly.
- Cloudflare publishes the `site/` folder every time a change is pushed to `main`.

## Making a change

1. Edit the text in `build.py` (or the styles in `site/css/styles.css`).
2. Run `python3 build.py` to regenerate the pages in `site/`.
3. Commit both `build.py` and `site/`, and push to `main`.
