Classes  /  Group 5: Mathematics

Mathematics: Applications & Interpretation

SLHL

Applications and Interpretation emphasises modelling, statistics and the use of technology to solve real problems. We focus on interpreting questions set in context, using the calculator well, and communicating results clearly.

Enquire about this subjectSee class slots

What we cover

  • Number and algebra, functions, geometry and trigonometry
  • Statistics, probability and data analysis
  • Mathematical modelling
  • Calculus in context
  • Using the graphic display calculator efficiently
  • Choosing a topic and writing the mathematical exploration (IA)
