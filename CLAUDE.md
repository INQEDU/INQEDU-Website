# Notes for Claude

- Static site, no framework. Page text lives in `build.py`; subject pages (including class slots) are generated from `subjects.py`; run `python3 build.py` after editing it, and commit `build.py` and the regenerated `site/` together.
- `site/css/styles.css`, `site/js/main.js` and `site/assets/` are hand-edited, not generated.
- Cloudflare deploys the `site/` folder from `main`. There is no build step on Cloudflare.
- Brand: fonts Libre Baskerville (display) and Almarai (body), self-hosted in `site/assets/fonts`. Colours #F6F3EC, #ECE4DA, #B9A590, #574C3F, #36302A.
- Eight subjects with equal emphasis on the classes pages: English A Language & Literature, English A Literature, Business Management, Economics, Geography, Psychology, Maths AA, Maths AI (all SL and HL). History is no longer offered. The homepage hero label reads "IB Tuition Specialists".
- Geography's assessment table shows only figures common to the current and revised courses. Psychology follows the revised course (first examined May 2027); its HL Paper 2/3 weightings are not shown because they were not confirmed. Verify before adding timings.
- Preview larger changes on a branch first: Cloudflare builds a preview for each branch.
- Enquiries go to WhatsApp (+65 8866 5396) via `whatsapp_link()` in `build.py`, which pre-fills a message; subject pages name the subject in it. There is no contact form.
- FAQ answers live in `FAQS` in `build.py` and appear at the bottom of the contact page (`contact.html#faq`). Do not add facts the owner has not confirmed (fees, class sizes, trial lessons, location, one-to-one lessons).
- Homepage class photos are in `site/assets/photos/`; metadata is stripped before adding. They show students, so confirm consent with the owner before adding new ones.
- The "Trusted by students from" belt (scrolls continuously in full colour, static for reduced motion) comes from `SCHOOLS` in `build.py`. A logo file in `site/assets/schools/<slug>.<ext>` replaces that school's text name automatically. Only add logos the owner supplies.
- Testimonials live in `TESTIMONIALS` in `build.py` (homepage, after the school belt). Quotes are verbatim from students; do not edit wording without the owner's say-so.
- The Guides page is switched off (`SHOW_GUIDES = False` in `build.py`) while the owner reworks it. Its layout and the three guides in `GUIDES` are kept; set it to True and rebuild to restore it, then remove the guides lines from `site/_redirects`.
- Tutor profiles live in `TUTORS` in `build.py` and build `tutor.html` (menu item "Tutor"). Add a dict to add a tutor. Lucas's write-up and quote are the owner's text; keep the wording.
- Stylesheet and script links carry a `?v=` fingerprint (`asset_version()` in `build.py`), so a style change reaches visitors without a hard refresh. Always rebuild after editing CSS or JS.
- SEO: every page gets a canonical URL (extensionless, https://www.inqedu.com/...), Open Graph tags, and the homepage carries EducationalOrganization + WebSite structured data (`ORG_JSON_LD`). `sitemap.xml` and `robots.txt` are generated by `build.py`. The site is registered in Google Search Console by the owner.
